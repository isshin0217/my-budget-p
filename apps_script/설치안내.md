# 폰에서 실시간으로 보기 — 설치 안내

카드 문자가 오면 아이폰이 구글 서버로 보내고, 구글이 파싱해서 시트에 적고,
**"₩304,511 left this week"** 을 알림으로 돌려준다. PC가 꺼져 있어도 동작한다.

```
[아이폰] 카드 문자 수신
   │  단축어 자동화 → 문자 텍스트를 웹앱에 POST
   ▼
[구글] Apps Script → 파싱 → 시트 기록 → 이번 주 남은 돈 계산
   │      ├─ 알림으로 응답 (문자 받자마자 뜸)
   │      └─ 웹 대시보드 (홈 화면 아이콘)
   ▼
[윈도우] (선택) 파이썬으로 엑셀 리포트
```

전체 15분쯤 걸린다. 1~5는 PC에서, 6~7은 아이폰에서.

---

## 1. 구글시트 만들기

[sheets.new](https://sheets.new) 로 새 시트를 만들고 이름을 `가계부` 로 바꾼다.
시트 탭(`Ledger`, `Settings`)은 스크립트가 알아서 만드니 그냥 두면 된다.

> 시트와 대시보드에 보이는 글자는 **영어**다.
> 코드 주석과 이 안내서는 한글이다.

## 2. 스크립트 붙여넣기

시트 상단 메뉴에서 **확장 프로그램 → Apps Script**.

편집기에 있는 `function myFunction() {}` 를 전부 지우고,
[`Code.gs`](Code.gs) 내용을 통째로 붙여넣는다.

## 3. 토큰 바꾸기 (건너뛰지 말 것)

파일 맨 위 `TOKEN` 을 길고 아무 의미 없는 문자열로 바꾼다.

```javascript
const TOKEN = 'k7x2m9qp4wz8vn3blahblah';
```

빈 값으로 두면 웹앱이 아무도 들여보내지 않는다 — 토큰 없이 열려 있는 것보다 낫다.

> **왜 필요한가**: 웹앱 URL은 "링크가 있는 누구나" 접근할 수 있게 열어야
> 단축어가 로그인 없이 보낼 수 있다. 즉 **URL을 아는 사람은 내 가계부를 볼 수 있다.**
> 토큰이 실질적인 비밀번호다. URL을 남에게 공유하지 말 것.

> **저장소에 올릴 때**: 이 값은 코드에 있으므로 깃 이력에 그대로 남는다. 여기서
> 지워도 옛 커밋에서 읽힌다. 공개 저장소로 올릴 거면 **먼저 값을 바꾸고**,
> 단축어와 대시보드 링크의 `?t=` 도 같이 고칠 것.

저장(<kbd>Ctrl</kbd>+<kbd>S</kbd>) 후 **⚙ 프로젝트 설정 → 시간대**가
`(GMT+09:00) 서울` 인지 확인한다.

## 4. 동작 확인

편집기 상단 **▶ 실행 버튼 오른쪽의 함수 드롭다운**에서 `runTest` 를 고르고 **실행**.

> 드롭다운은 기본적으로 파일의 첫 번째 함수(`classify_`)에 맞춰져 있다.
> 그대로 실행하면 아무 일도 없이 1초 만에 "완료됨"만 뜬다. **반드시 `runTest` 로 바꿀 것.**

- 처음이면 권한 승인 창이 뜬다 → 계정 선택 → "고급" → "...(안전하지 않음)으로 이동" → 허용
  (내가 만든 스크립트라 나오는 경고다)
- 실행 로그에 이렇게 찍히고, 시트에 행이 생기면 성공

```
Parsed OK: 스타벅스 강남 6500
Saved: true
₩... left this week · prepay ₩6,500
```

> 권한 승인 창이 안 뜨고 로그도 비어 있으면 `runTest` 가 아닌 다른 함수가 실행된 것이다.

## 5. 웹앱으로 배포

**배포 → 새 배포 → ⚙ → 웹 앱** 선택 후:

| 항목 | 값 |
|---|---|
| 실행 계정 | **나** |
| 액세스 권한 | **링크가 있는 모든 사용자** |

배포를 누르고 나오는 **웹 앱 URL** 을 복사한다. 이렇게 생겼다:

```
https://script.google.com/macros/s/AKfycbx...../exec
```

여기에 토큰을 붙인 게 최종 주소다. 메모해 둘 것:

```
https://script.google.com/macros/s/AKfycbx...../exec?t=k7x2m9qp4wz8vn3blahblah
```

브라우저에서 열어 대시보드가 뜨면 성공.

### ⚠️ 코드를 고쳤으면 반드시 재배포

**저장(Ctrl+S)만으로는 반영되지 않는다.** `/exec` 주소는 배포 당시 코드의 *사본*을
실행하기 때문에, 재배포하지 않으면 옛 코드가 계속 돈다.

```
배포 → 배포 관리 → ✏️ 연필 → 버전: [새 버전] → 배포
```

**"새 배포"가 아니라 "배포 관리 → 연필"** 로 해야 URL이 그대로 유지된다.
새 배포로 하면 주소가 새로 발급돼서 단축어와 홈 화면 아이콘을 전부 고쳐야 한다.

토큰을 바꿨을 때도 마찬가지다. 이걸 안 하면 `Invalid link` 가 뜬다.

## 6. 아이폰 단축어 자동화

> 메뉴명은 **영어 설정 기준**. 한글 폰이면 괄호 안 이름으로 보면 된다.

**Shortcuts**(단축어) 앱 → 하단 **Automation**(자동화) → 우측 상단 **+** → **Message**(메시지)

### 6-1. 트리거

| 항목 | 값 |
|---|---|
| **Message Contains** | `승인` |
| **Sender** | 비워둠 |
| **Run Immediately** | 선택 ← 탭 없이 자동 실행 |

**Next** → **New Blank Automation**

### 6-2. 동작 3개

`Search Actions` 칸에서 이름으로 검색해 차례로 추가한다.

**① `Get Contents of URL`**

URL 칸에 5번의 주소(`...exec?t=토큰`)를 붙여넣는다. 그다음이 함정:

> **URL 아래 왼쪽의 동그란 `⌄` 화살표를 탭해야** Method 등이 펼쳐진다.
> 예전 iOS의 "Show More" 가 화살표로 바뀌었다. 이걸 못 찾아 헤매기 쉽다.

펼친 뒤:

| 항목 | 값 |
|---|---|
| Method | `POST` |
| Request Body | `JSON` |
| Add new field → Text | Key `text` / Value **Shortcut Input** |

`Value` 는 **직접 타이핑하지 말고** 키보드 위 파란 변수에서 `Shortcut Input` 을 고른다.
이게 받은 문자 내용이다.

**② `Get Dictionary Value`**

| 항목 | 값 |
|---|---|
| Get | `Value` |
| for | `message` |
| in | **Contents of URL** |

**③ `Show Notification`** — 내용에 **Dictionary Value** 변수를 넣는다.

완성된 모습:

```
Receive messages as input
Get contents of https://...      (POST · JSON · text = Shortcut Input)
Get Value for message in Contents of URL
Show notification  Dictionary Value
```

우측 상단 **✓** 로 저장.

### 6-3. 테스트

**▶ (재생)** 버튼을 누른다. 문자가 없으니 빈 값이 가고,
**`Couldn't read this message`** 알림이 뜨면 **성공**이다 — URL·토큰·POST·JSON이 모두 정상이라는 뜻.

이어서 **메시지 앱에서 본인 번호로** 아래를 보내 실제 동작을 확인한다:

```
신한카드(1234)승인 홍*동 6,500원(일시불)07/21 13:15 스타벅스 강남
```

### 6-4. 취소 문자도 잡으려면

필터가 `승인` 이라 **취소/환불 문자는 안 잡힌다.** 파서는 취소를 음수로 처리할 준비가
돼 있지만 문자가 안 오면 소용없다. 환불이 반영 안 되면 남은 돈이 실제보다 적게 나온다.

**자동화를 하나 더 만들어** 필터만 `취소` 로 두고 나머지는 똑같이 설정하면 된다.

> **"Run Immediately"가 안 보이면**: iOS 버전이 낮은 것이다.
> 알림을 한 번 탭해야 실행된다. 완전 무인은 아니지만 흐름은 같다.

## 7. 홈 화면에 대시보드 추가

### 방법 A — 단축어로 (권장, 확실함)

iOS가 `script.google.com` 을 구글 앱으로 가로채서 **Safari에서 안 열리는 경우가 많다**
("현재 파일을 열 수 없습니다"). 그럴 땐 Safari를 아예 안 거치는 이 방법을 쓴다.

**Shortcuts** 앱 → 하단 **Shortcuts** 탭 → **+** → 동작 3개:

| 순서 | 동작 | 설정 |
|---|---|---|
| ① | `Text` | 주소 뒤에 **`&view=text`** 를 붙여 통째로 붙여넣기 |
| ② | `Get Contents of URL` | URL 칸에 변수 **`Text`** 선택 (타이핑 금지) |
| ③ | `Show Result` | 설정 없음 |

> **왜 `Text` 동작을 앞에 두나**: `Get Contents of URL` 의 URL 칸은 붙여넣기를
> 거부하는 iOS 버그가 있다. `Text` 칸은 정상 동작하므로 거기 넣고 변수로 넘긴다.

이름을 `가계부` 로 저장 → **Add to Home Screen**.

누르면 이렇게 뜬다:

```
Left to spend this week
₩304,511

07/20 - 07/26 · 6 days left
₩50,751 a day

Spent    ₩138,500 / ₩443,011
Prepay   ₩211,400

This week
  스타벅스 강남  ₩6,500
```

### 방법 B — Safari로 (되면 더 예쁨)

Safari에서 최종 주소(`?t=토큰`, `&view=text` **없이**)를 열고
**공유 → 홈 화면에 추가**. 그래프와 색이 있는 HTML 대시보드가 나온다.

폰에서 안 열리면 방법 A로 가면 된다. 기능 차이는 없다.

문자 알림을 놓쳐도 여기서 이번 주 남은 돈을 언제든 확인할 수 있다. 90초마다 자동 새로고침.

## 쓰면서 할 일

### 예산 설정
시트의 `Settings` 탭에서 고친다.

| 항목 | 설명 |
|---|---|
| `Monthly budget` | 실제 값으로 바꿀 것 (기본 200만원) |
| `Cycle length (days)` | **선결제 간격.** 7이면 주 단위, 10이면 10일마다 |
| `Cycle starts on` | 주기가 시작된 아무 과거 날짜. **7일이 아니면 반드시 적을 것** |
| `Cycle budget` | 한 주기에 자유롭게 쓸 돈. 0이면 월 예산에서 계산 |
| `Week starts on` | 7일 주기일 때의 시작 요일. 시작 날짜를 적으면 무시됨 |
| `Fixed costs (manual)` | 0이면 자동 감지만 사용 |

### 선결제 간격이 7일이 아닐 때

10일마다 선결제한다면 `Cycle length (days)` 를 `10`, `Cycle starts on` 에
주기가 시작된 날짜(예: `2026-08-01`)를 적는다. 그러면 요일과 무관하게
08/01~08/10, 08/11~08/20 … 으로 정확히 끊긴다. **달이 바뀌어도 어긋나지 않는다.**

`Cycle budget` 에 `1000000` 을 적으면 **10일에 100만원**이 한도가 된다.
이 값은 **고정비를 이미 뺀 자유 지출액**으로 본다 — 월세·구독료를 또 빼지 않는다.

비워두면(0) 예전처럼 `월 예산 − 고정비` 를 주기 길이만큼 잘라 쓴다.

> 주기가 7일이 아니면 화면 문구도 `this week` 대신 `this cycle` 로 바뀐다.

> **`Cycle starts on` 을 비워두면** 고정된 기준점에서 기계적으로 끊는다. 주기가
> 겹치거나 자투리가 생기지는 않지만, 시작일이 내 선결제 날짜와 안 맞을 수 있다.
> 7일이 아닌 주기를 쓸 거면 되도록 적어두자.

### 태그 달기
`Ledger` 시트의 노란 **`Tag`** 칸에 `Date night`, `Trip` 처럼 직접 적는다.
문자만 봐선 알 수 없는 것들이다.

**같은 가맹점은 다음부터 자동으로 같은 태그가 붙는다.** 쓸수록 손이 덜 간다.

### 시트에 보이는 값

| 열 | 값 |
|---|---|
| `Category` | `Food`, `Cafe`, `Groceries`, `Delivery`, `Taxi`, `Transportation`, `Online`, `Phone`, `Medicine`, `Subscription`, `Clothing/Beauty`, `Household`, `Gifts`, `Housing/Bills`, `Uncategorized` |
| `Merchant` | 카드 문자에 찍힌 그대로 (한글 가맹점명) |
| `Tag` | **사람이 적는 칸.** 노랗게 칠해져 있다 |

> 숨은 칸이 둘 있다. `MerchantEN`(저장할 때 한 번 번역해 담아두는 값)과
> `AutoCategory`(저장하던 그때 규칙이 뭐라고 했는지). 둘 다 코드가 쓰는 칸이라
> 손대지 않는 게 좋다. 열 머리글 사이의 화살표를 누르면 펼쳐진다.

> 예전에 있던 `Type`(Daily/Weekly/Fixed) 열은 없앴다. 카테고리에서 자동으로
> 따라오는 값인데 정작 앱 어디에서도 읽지 않았다. **Clean up ledger** 를 한 번
> 누르면 이미 만들어진 시트에서도 지워진다.

### 정기 지출 — `Fixed` 시트

| Name | Amount | Every | Paid by | Note |
|---|---|---|---|---|
| 월세 | 700000 | `Month` | `Bank` | 계좌이체 |
| SKT | 55000 | `Month` | `Card` | 카드 자동결제 |
| 청소 아주머니 | 35000 | `Week` | `Cash` | **한 번 올 때** 금액 |
| 출근 택시 | 12000 | `Mon-Fri` | `Card` | **하루치** 금액 |

**`Every`** — 얼마나 자주 나가는가. 적는 금액이 1회분인지 하루치인지가 다르다.

| 값 | 언제 | 적는 금액 |
|---|---|---|
| `Month` | 매달 1회 | 한 달치 |
| `Week` | 매주 1회 | **1회분** |
| `Mon-Fri` | 평일마다 | **하루치** |
| `Day` | 주말 포함 매일 | **하루치** |

> `Weekday` 라고 적어도 `Mon-Fri` 와 같게 동작한다. 다만 한글로 읽으면 "주당"으로
> 오해하기 쉬워 `Mon-Fri` 를 쓴다. 비워두면 `Month` 로 본다.

- **`Month`** → 월 예산에서 빠진다 (주간 한도가 그만큼 낮아짐)
- **`Week` / `Weekday` / `Day`** → **이번 주 남은 돈에서 미리 빠진다**

> **왜 미리 빼나**: 택시비·청소비는 이미 임자가 있는 돈이다. 남은 돈에 섞여 있으면
> 쓸 수 있는 것처럼 보인다. 미리 빼두면 "진짜 자유롭게 쓸 수 있는 돈"만 남는다.

**`Paid by` 가 핵심이다.**

- **`Bank`** / **`Cash`** — 월세·보험료·청소비처럼 **카드를 안 거치는** 돈.
  카드 문자가 안 오니 자동 감지가 영원히 못 잡는다. 여기 적어야만 반영된다.
- **`Card`** — 카드 결제. Ledger 에도 찍히므로 **두 번 세지 않도록** 처리된다.

### 예약이 움직이는 방식

예약은 **`남은 횟수 × 하루치`** 로 계산한다. 지나간 날은 세지 않는다.

**예상대로 쓰면 남은 돈이 흔들리지 않는다.** 택시를 타면 변동비가 늘지만
예약이 같은 만큼 줄어서 상쇄된다. 이미 계산에 넣어둔 지출이기 때문이다.

```
월  택시 12,000    예약 83,000   남은 돈 191,207
화  택시 12,000    예약 71,000   남은 돈 191,207   ← 안 움직임 (예상한 지출)
수  저녁 43,000    예약 59,000   남은 돈 148,207   ← 움직임 (계획 밖 지출)
```

**덜 쓰면 늘어난다.** 수·목에 걸어서 출근하면 그 이틀치가 예약에서 빠져 돌아온다.

```
수  (택시 안 탐)   예약 71,000   남은 돈 148,207
목  (택시 안 탐)   예약 59,000   남은 돈 160,207   ← +12,000
금  택시 12,000    예약 35,000   남은 돈 172,207   ← +12,000
```

**더 쓰면 줄어든다.** 주말에 택시를 두 번 더 타면 예약과 무관하게 그대로 반영된다.

```
토  택시 12,000    예약 35,000   남은 돈 136,207   ← -12,000
일  택시 12,000    예약 35,000   남은 돈 124,207   ← -12,000
```

> 현금·이체 항목은 결제 내역이 없으므로 남은 횟수만으로 계산한다.
> 주 1회짜리(청소비 등)는 그 주가 끝날 때까지 계속 잡혀 있다.

### 카드로 결제하면 예약이 사라진다 — 이름이 이어져야 한다

`Paid by` 가 `Cash` 여도 카드 내역은 항상 확인한다. 평소 현금으로 주다가
어쩌다 카드로 긁는 경우가 있기 때문이다.

문제는 **카드 문자에 찍히는 가맹점명이 내가 부르는 이름과 다르다**는 것이다.
`청소 아주머니` 로 적어놨는데 문자에는 `홈클리닝서비스` 가 찍힌다. 그러면 둘을 못 이어서
**예약과 카드 지출이 둘 다 잡혀 같은 돈이 두 번 빠진다.**

| 상황 | 예약 | 지출 | 남은 돈 |
|---|---|---|---|
| 현금으로 줌 | 35,000 | 0 | 251,207 |
| 카드 · 이름이 그대로 찍힘 | 0 | 35,000 | 251,207 ✅ |
| 카드 · 이름 다름, 태그 없음 | 35,000 | 35,000 | **216,207 ❌** |
| 카드 · 태그로 연결 | 0 | 35,000 | 251,207 ✅ |

**해결 1 (권장) — `Name` 을 카드 문자에 찍히는 이름에 맞춘다**

`Ledger` 시트의 `Merchant` 열을 보고 그대로 복사해 쓴다. 매칭은 **양방향 부분 일치**라
일부만 적어도 된다. `카카오T택시 A1234` 처럼 뒤가 매번 바뀌면 `카카오T` 만 적는 게 낫다.

> 너무 짧게 적으면 엉뚱한 게 걸린다. `GS` 는 `GS25`(편의점)와 `GS칼텍스`(주유)를
> 둘 다 잡아버린다. 구별되는 만큼은 적을 것.

**해결 2 — 이름으로 안 되면 태그로**

`Ledger` 의 노란 `Tag` 칸에 Fixed 항목 이름(`청소 아주머니`)을 적으면 이어준다.
문자에 찍히는 이름이 전혀 다르거나 매번 바뀔 때 쓴다.

**한 번만 하면 된다.** 태그 학습 덕분에 같은 가맹점의 다음 결제부터는 자동으로 붙는다.

### 자동 감지를 기다리지 말 것

구독료·통신비는 **`Fixed` 시트에 적으면 즉시** 월 고정비로 잡힌다.
자동 감지(26~35일 간격 2회)는 적어두는 걸 깜빡했을 때의 보험일 뿐이다.

적어두지도 않고 감지도 안 된 상태에서 결제되면, 그 돈은 그냥 **이번 주 변동비**로
잡힌다. 계산에서 사라지지는 않지만 그 주가 유난히 빡빡해 보인다.

카드 고정비는 여기 안 적어도 **2개월치가 쌓이면 자동으로 잡힌다**
(같은 가맹점이 26~35일 간격, 금액 15% 이내 반복). 목록에 적은 건 목록이 우선이고,
목록에 없는 것만 자동 감지가 보충한다.

**마지막 결제가 40일을 넘으면 자동 감지에서 풀린다.** 구독을 해지하면 다음 달에
저절로 예산이 돌아온다. 이게 없으면 작년에 두 번 가고 만 미용실이 지금까지
매달 예산을 깎는다 — 화면에는 이름만 스칠 뿐이라 눈치채기 어렵다.

### 이름은 정확히 적을 것

`Match`(비우면 `Name`)를 카드 문자의 가맹점명과 맞춰 "이건 이미 예산에 넣은 돈"으로
판단한다. 맞추기가 느슨해서 **`GS` 처럼 짧게 적으면 `GS25` 편의점까지 걸린다.**

걸리더라도 **적어둔 금액만큼 한 건만** 빠지므로 나머지 편의점 결제는 정상적으로
변동비에 잡힌다. 다만 어느 한 건이 엉뚱하게 빠질 수는 있으니, 카드 문자에 실제로
찍히는 상호를 `Match` 에 그대로 적는 게 가장 정확하다.

> 금액이 `0` 인 줄은 계산에서 무시된다. 처음 만들어지는 `(예시)` 줄들이 그래서 0이다.
> 지우지 않아도 숫자가 틀어지지 않는다.

고정비는 **월 예산에서 미리 빼므로 주간 한도를 줄인다.** 다만 카드로 나간 것은
실제 청구되므로 **선결제 금액에는 포함**된다. 이 둘을 구분하는 게 이 가계부의 핵심이다.

### 환급·캐시백 — `Extra` 시트

| Date | Name | Amount | Note |
|---|---|---|---|
| 2026-07-21 | 보험료 환급 | 320000 | + 는 들어온 돈 |
| 2026-07-15 | 병원비 (현금) | -80000 | - 는 카드 밖 지출 |

**그 달 예산에 더해져 남은 주에 고르게 퍼진다.** 환급 32만원을 받으면 주간 한도가
약 7만 3천원씩 올라간다. 받은 주에 몰아서 쓰지 않게 하려는 의도다.

`Date` 의 **월**만 본다. 그 달이 지나면 자동으로 계산에서 빠진다.

### 통장 잔액 예측 — `Settings` + `Fixed` 의 `Day`

"25일에 월세 나갈 때 통장에 돈이 있나"를 미리 보여준다. 주간 예산과는 다른 질문이다.

`Fixed` 시트의 **`Day`** 열에 결제일을 적는다 (월세 `25`, 통신비 `15`).
월 단위 항목에만 의미가 있다. 그 달에 없는 날짜(2월 31일 등)는 말일로 당긴다.

`Settings` 에 네 가지를 채운다:

| 항목 | 설명 |
|---|---|
| `Account balance` | 지금 통장에 있는 돈. **0이면 예측을 건너뛴다** |
| `Balance as of` | 위 금액을 적어둔 날짜. 비우면 오늘로 본다 |
| `Monthly income` | 매달 들어오는 급여 |
| `Payday` | 급여일 (1~31) |

그러면 앞으로 35일을 하루씩 굴려 **최저 잔액과 그 날짜**를 보여준다.
0 밑으로 내려가면 경고가 뜬다.

```
Lowest balance ₩734,000 around 07/24
  07/25  Salary    ₩2,500,000
  07/25  월세         -₩700,000
  08/15  SKT          -₩55,000
```

> **은행과 연결된 게 아니다.** `Account balance` 는 직접 적는 값이라 시간이 지나면
> 실제와 벌어진다. 대신 `Balance as of` 가 과거면 그날부터 굴려오므로
> **오래된 값일수록 낮게 잡힌다.** 가끔 갱신해 주는 게 좋다.
>
> 매일 빠지는 돈은 `(월 예산 − 월 고정비) ÷ 30` 으로 추정한다. 실제 소비 습관이
> 이와 다르면 예측도 그만큼 어긋난다.

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| **`Conversion Error: couldn't convert from Rich Text to Dictionary`** | **배포의 `액세스 권한`이 `링크가 있는 모든 사용자`가 아님.** 단축어는 구글 로그인 없이 요청하므로 로그인 HTML이 돌아오고, 그걸 JSON으로 못 바꿔서 나는 에러. 배포 관리 → 연필 → 액세스 권한 변경 → 새 버전 배포 |
| 폰 Safari에서만 안 열림 | 위와 같은 원인일 때가 많다. 액세스 권한부터 확인할 것 |
| `Invalid link` | 대개 **재배포를 안 한 것**. 코드의 TOKEN을 바꿨는데 배포된 사본은 옛 토큰을 쓰는 중. 위 "재배포" 참고. URL의 `?t=` 값이 코드의 TOKEN과 글자 그대로 같은지도 확인 |
| `Not authorized` | URL 뒤 `?t=토큰` 이 빠졌거나 `Code.gs` 의 TOKEN과 다름. `/dev` 가 아닌 `/exec` 인지도 확인 |
| `Couldn't read this message` | 카드사 문자 형식이 다름. 문자 원문을 모아 `CATEGORY_RULES`/정규식 보강 필요 |
| 실행 로그가 비어 있음 | 드롭다운이 `runTest` 가 아닌 다른 함수에 맞춰져 있음 |
| 알림이 안 뜸 | 자동화의 "즉시 실행"이 꺼져 있거나, 문자에 `승인` 이 없음 |
| 고친 게 반영 안 됨 | 배포 관리에서 **새 버전**으로 다시 배포해야 함 |
| 날짜가 작년으로 | 카드 문자에는 연도가 없어 추정한다. 미래 날짜면 작년으로 본다 |

## 파이썬은 계속 쓰나?

구글시트가 **살아있는 가계부**가 되고, 파이썬은 선택이 된다.
시트를 `.xlsx` 로 내보내면 기존 `report.py` 로 월간 리포트를 만들 수 있다.
파싱·계산 로직은 양쪽이 같은 모델이라 숫자가 일치한다.
